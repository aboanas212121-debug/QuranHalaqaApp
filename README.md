# حلقتي — تطبيق إدارة حلقات تحفيظ القرآن الكريم

تطبيق Android خفيف وسريع، يعمل بالكامل بدون إنترنت، لمساعدة معلم الحلقة على تسجيل
حضور وحفظ ومراجعة الطلاب يوميًا، وإصدار تقرير أسبوعي احترافي بصيغة PDF لإرساله للمدير.

---

## 1) الاختيار التقني والتبرير

| العنصر | الاختيار | السبب |
|---|---|---|
| اللغة | Kotlin 100% | أداء أعلى واستهلاك ذاكرة أقل من Flutter على الأجهزة القديمة |
| الواجهة | Jetpack Compose + Material 3 | دعم RTL أصيل من النظام، بدون تبعيات إضافية |
| قاعدة البيانات | Room (SQLite) | محلية، بدون إنترنت، ناضجة ومدعومة رسميًا من Google |
| PDF | `android.graphics.pdf.PdfDocument` (أصلي) | **حسب اختيارك**: صفر تبعيات خارجية، أخف حجمًا |
| الرسوم البيانية | Compose Canvas مخصص | بدون مكتبة خارجية (نفس فلسفة التخفيف) |
| حقن التبعيات | يدوي عبر `ViewModelFactory` | تفادي Hilt/Koin لتقليل حجم APK وتعقيد البناء |
| المعمارية | MVVM + Repository Pattern | تسمح لاحقًا بإضافة مصدر بيانات سحابي بدون إعادة كتابة الشاشات |

## 3) طريقة التشغيل والبناء (APK)

> **ملاحظة مهمة**: هذا الكود كُتب في بيئة عمل بدون Android SDK ومستودعات Google Maven،
> لذا لم يتم تشغيل Gradle Build فعليًا هنا. اتبع الخطوات التالية على جهازك لبناء وتشغيل
> المشروع، وأبلغني بأي خطأ Compile يظهر لأصلّحه فورًا.

1. ثبّت **Android Studio** (إصدار Koala أو أحدث يُفضّل).
2. افتح المجلد `QuranHalaqaApp` عبر `File > Open`.
3. انتظر **Gradle Sync** التلقائي (يحتاج اتصال إنترنت لتنزيل التبعيات أول مرة فقط).
4. لتشغيل التطبيق على المحاكي أو جهاز حقيقي: زر **Run ▶** أو `Shift+F10`.
5. لإصدار APK قابل للتوزيع:
   - `Build > Build Bundle(s) / APK(s) > Build APK(s)` لملف تجريبي سريع، أو
   - `Build > Generate Signed Bundle / APK` لإصدار موقّع جاهز للنشر (يتطلب إنشاء Keystore).
6. الملف الناتج يكون في: `app/build/outputs/apk/debug/app-debug.apk` (أو `release/` للموقّع).

### تثبيت مباشر عبر ADB
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

## 4) اختبار أهم الوظائف (Checklist يدوي)

| الوظيفة | خطوات الاختبار | النتيجة المتوقعة |
|---|---|---|
| إضافة طالب | إدارة الطلاب → + → إدخال اسم وحلقة → حفظ | يظهر الطالب في القائمة فورًا |
| البحث | كتابة جزء من اسم في حقل البحث | تُفلتر القائمة حيًا (Reactive عبر Flow) |
| تعديل/حذف طالب | ضغط أيقونة القلم/السلة على بطاقة طالب | تحديث البيانات أو اختفاء الطالب من القوائم (حذف ناعم) |
| التسجيل اليومي | التسجيل اليومي → اختيار "حاضر" لطالب | يُحفظ فورًا (Auto-save) بدون الحاجة لزر حفظ منفصل للحضور |
| تفاصيل الحفظ/المراجعة | فتح تفاصيل بطاقة طالب → تعبئة الحقول → "حفظ تفاصيل اليوم" | تُخزَّن القيم وتظهر عند إعادة فتح البطاقة لاحقًا |
| لوحة التحكم | فتح الشاشة الرئيسية بعد تسجيل عدة طلاب | الأرقام والنسب والرسم البياني تتحدث تلقائيًا |
| التقرير الأسبوعي | إدخال اسم الحلقة والمعلم → "إنشاء التقرير الأسبوعي" | يظهر اسم ملف PDF، ويُحفظ في `Android/data/.../files/reports` |
| مشاركة PDF | ضغط "مشاركة عبر واتساب" أو "مشاركة (بريد/حفظ)" | تفتح واتساب مباشرة أو قائمة المشاركة العامة لأندرويد |
| النسخ الاحتياطي | الإعدادات → "إنشاء نسخة احتياطية الآن" | يظهر ملف `.db` جديد في القائمة بالتاريخ والوقت |
| الاستعادة | الإعدادات → اختيار نسخة → "استعادة" → تأكيد | تُستبدل قاعدة البيانات، ثم يجب إعادة تشغيل التطبيق يدويًا |
| العمل بدون إنترنت | تفعيل وضع الطيران ثم استخدام كل الشاشات | يعمل التطبيق بالكامل بدون أي خطأ اتصال |

## 5) تحسينات مستقبلية مقترحة

**قصيرة المدى (سهلة الإضافة على البنية الحالية):**
- شاشة إعدادات دائمة لحفظ اسم الحلقة/المعلم بدل إدخالهما في كل مرة (`DataStore Preferences`).
- إشعار محلي (Notification) تذكيري للمعلم في وقت الحلقة يوميًا.
- تصدير التقرير الأسبوعي كـ Excel/CSV بجانب PDF.
- إضافة خط عربي مخصص (Tajawal/Cairo) في `res/font` لمظهر أكثر تميزًا.
- رسم بياني لتطور حفظ كل طالب عبر الأسابيع (خط زمني ممتد، وليس أسبوعًا واحدًا فقط).

**متوسطة المدى (تتطلب توسعة في نموذج البيانات):**
- **أكثر من معلم / أكثر من حلقة**: إضافة كيان `Teacher` و`Halaqa`، وربط الطلاب والسجلات بمعرّف الحلقة بدل حقل نصي `groupName`.
- **حسابات مستخدمين**: شاشة تسجيل دخول بسيطة (PIN محلي أو حساب) قبل الوصول للبيانات.
- **صلاحيات**: تمييز دور "معلم" عن دور "مدير" في نفس قاعدة البيانات المحلية أولًا، تمهيدًا للمزامنة.

**طويلة المدى (تتطلب خادمًا خلفيًا):**
- **مزامنة سحابية**: إضافة طبقة `RemoteDataSource` (مثلًا عبر Firebase Firestore أو REST API) في نفس بنية Repository الحالية دون تعديل الشاشات، مع دمج `WorkManager` للمزامنة في الخلفية عند توفر الإنترنت.
- **لوحة تحكم للمدير**: تطبيق ويب أو تطبيق Android منفصل يقرأ من نفس الخادم السحابي، يعرض بيانات كل الحلقات والمعلمين مجمّعة.
- **نسخ احتياطي سحابي تلقائي** بدل الاعتماد فقط على الملف المحلي.

## 6) ملاحظات هامة

- **الأمان**: البيانات محفوظة بالكامل داخل مساحة تخزين التطبيق الخاصة (Sandboxed)، ولا تُرسل لأي خادم خارجي في النسخة الحالية.
- **الأداء**: `minSdk = 23` يضمن التوافق مع أجهزة أندرويد 6.0 فأعلى (تغطية واسعة للأجهزة المتوسطة/القديمة)، وقاعدة البيانات محلية بالكامل بدون أي طلب شبكي.
- إذا واجهتك أي رسالة خطأ أثناء Gradle Sync أو البناء (خصوصًا حول إصدارات المكتبات)، أرسل لي نص الخطأ كاملًا وسأعدّل الإصدارات المطلوبة فورًا.
